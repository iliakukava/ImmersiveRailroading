Model scripts
A rolling stock definition can set "script" to a .lua path in the resource pack, or to the script text itself. The script is compiled when the pack loads. A syntax error is reported for that file and does not stop the rest of the pack. Run /immersiverailroading packreport to list every failed pack file.

Events: on_load, on_tick, on_client_tick, on_control, on_door, on_couple, on_uncouple, on_mount, on_dismount. on_tick runs on both sides. set_control and set_door only change state on the server. rotate_group, translate_group and group_visible change how the model is drawn on the side that runs the event.

The stock argument exposes id, name, uuid, texture, speed, gauge, tick, passengers, server, control, pressed, set_control, door_open, set_door, coupled, rotate_group, translate_group, group_visible, clear_pose and log. Angles passed to rotate_group are degrees. Full notes and an example are in docs/lua-model-scripts.md in the mod sources.
