Model scripts
A rolling stock definition can set "script" to a .lua path in the resource pack, or to the script text itself. The script is compiled when the pack loads. A syntax error is reported for that file and does not stop the rest of the pack. Run /immersiverailroading packreport to list every failed pack file.

Events: on_load, on_tick, on_client_tick, on_control, on_door, on_couple, on_uncouple, on_mount, on_dismount. on_tick runs on both sides. set_control and set_door only change state on the server. rotate_group, translate_group and group_visible change how the model is drawn on the side that runs the event.

The stock argument exposes id, name, uuid, texture, speed, gauge, tick, passengers, server, control, pressed, set_control, door_open, set_door, coupled, rotate_group, translate_group, scale_group, pivot_group, set_glow, set_alpha, gif, part, throttle, reverser, brakes, horn, bell, emergency, derail, explode, group_visible, clear_pose and log. part(group) returns move, rotate, scale, pivot, glow, alpha, visible and gif for that mesh group. Name a group GLASS for blended glass, or set dissolve with d or Tr in the MTL. Normal maps use map_Bump or a _n texture. Roughness and specular use map_Pr, map_Ns or a _s texture; height can be supplied as map_height and is sampled in the normal slot the way Iris reads labPBR maps. AO should be baked into the albedo. GIF clips are declared with gif(group, path) or a gifs block in the stock json. /crack derails the consist you are riding. /explossuion explodes it. Full notes are in docs/lua-model-scripts.md.
